FIVE RIVERS REAL ESTATE — REDESIGN PACKAGE

This package is a drop-in redesign for the existing GitHub Pages repository:
https://github.com/fiveriversre/fiveriversre.github.io

What changed
- Modern commercial-real-estate positioning
- Deep navy / warm white / muted gold visual system
- Existing Five Rivers logo retained
- Homepage centered on “Connecting Buyers & Businesses Across Washington”
- BUY A BUSINESS -> opportunities path
- SELL A BUSINESS -> confidential seller inquiry
- Featured Opportunities page
- About and Contact refresh
- Responsive navigation and mobile layout
- Instagram section updated to use Instagram's public embed script rather than SnapWidget

Deployment
1. Back up the current GitHub repository.
2. Replace the existing HTML/CSS/JS files with the files in this package.
3. Keep your existing image files and CNAME file in the repository.
4. Commit the changes to main.
5. GitHub Pages should publish the redesign on your existing domain.

Important
- I did not change your live GitHub repository.
- I did not change your Squarespace domain settings.
- The Instagram section currently uses the profile URL as an embed placeholder. For the final production homepage, it is better to select 2–3 specific public posts and paste their post URLs into the two Instagram blockquotes so the site shows actual opportunity posts rather than the profile itself.
- The seller form uses a mailto action because this site is static. A hosted form endpoint can be added later for a more polished submission experience.
